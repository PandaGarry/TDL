# Оригинальный нейминг долины и локализация RU/EN

Статус: **рабочий стандарт раунда 8**. Автор отклонил первую редакцию
названий и имён раунда 7 как слишком древнерусскую. Мир, язык, поселения
и люди должны быть вымышленными и гармонично работать в многоязычной
игре. Конкретный момент выпуска английского перевода ещё не выбран:
автор допускает перевод ближе к концу Act I либо RU/EN с самого начала.
Независимо от срока тексты и данные должны быть готовы к локализации.

## 1. Главный принцип

> **Собственное имя — не переводимая фраза, а стабильный объект данных.**

Для каждого имени храним:

- внутренний ID: `settlement_nivara`, `npc_sarela`;
- латинскую мастер-форму: `Nivara`, `Sarela`;
- русскую дисплейную форму: `Нивара`, `Сарела`;
- тип: река, поселение, человек, дом/хозяйство, вид, предмет;
- грамматические метаданные для русского: род, одушевлённость,
  склоняемость;
- внутреннюю этимологию из вымышленного языка для сценаристов;
- при необходимости подсказку произношения для актёров/локализаторов.

Английская версия использует латинскую мастер-форму без перевода смысла.
Русская версия использует согласованную транслитерацию. Описательные
слова переводятся отдельно: не «Silent Stones» вместо `Kevar`, а
`Kevar` в обеих версиях и пояснение «место слушания» только там, где это
нужно лору.

## 2. Звуковой образ языка долины Севары

Это не реконструкция древнерусского, славянских, германских или иного
реального исторического языка. Рабочий звуковой набор намеренно прост для
русского и английского чтения:

- гласные: `a e i o u`;
- согласные: `b d g h k l m n r s t v z`;
- преимущественно открытые слоги и слова из 2–3 слогов;
- ударение для произношения — на предпоследний слог, если позже культура
  не получит другого правила;
- без апострофов, диакритики, `q`, `x`, `y`, `j`, `w` и трудных кластеров;
- имена людей не обязаны означать профессию; роль и принадлежность к
  хозяйству хранятся отдельно.

Транслитерация:

| Latin | Русский | Примечание |
|---|---|---|
| a | а | |
| e | е; в начале слова — э | `Evaren` → `Эварен`, чтобы не читать как «Еварен» |
| i | и | |
| o | о | |
| u | у | |
| h | х | `Heravo` → `Хераво` |
| b d g k l m n r s t v z | б д г к л м н р с т в з | без дополнительных букв |

Русская грамматика: имена на `-а` склоняются как обычные имена
собственные; имена на `-о`, `-е`, `-и` по умолчанию несклоняемые; мужские
и нейтральные имена на согласный могут склоняться, женские иностранные
на согласный помечаются индивидуально. Точный род NPC не выводится
автоматически из окончания имени и хранится в данных персонажа.

## 3. Внутренние корни топонимов

Этимология нужна авторам мира, чтобы новые названия звучали из одной
культуры. Игроку её не обязаны объяснять при каждом упоминании.

| Корень | Значение внутри мира |
|---|---|
| `se` | течение, движущаяся вода |
| `vara` | широкая река |
| `niva` | укрытый изгиб / дом у воды |
| `rel` | боковой рукав, протока |
| `kava` | переход через воду |
| `mula` | мелкая тростниковая вода |
| `hera` | высокая открытая земля |
| `vena` | тёплый склон |

| `keva` | слушание, тишина внимания |

## 6. Правила создания новых имён

1. Сначала определить тип объекта и ID.
2. Собрать имя из звукового набора и, для топонима, осмысленного корня.
3. Проверить, что имя легко прочитать вслух по-русски и по-английски.
4. Проверить близкие совпадения с именами в этом документе, чтобы NPC не
   путались на слух.
5. Не использовать прямые исторические, религиозные и этнические имена
   как основу культуры долины.
6. Перед публичным анонсом выполнить отдельную проверку на крупные
   франшизы, товарные знаки и нежелательные значения в целевых языках.
7. Сразу добавить имя сюда, в глоссарий и в данные мира; не оставлять его
   только в диалоге или имени файла.

## 7. Локализационный конвейер

- Все строки UI, диалогов, журнала, хроники и системных сообщений получают
  стабильные ключи с первого текста, а не вшиваются в код на русском.
- Имена собственные подставляются из данных по ID, поэтому переводчику не
  нужно искать их внутри предложений.
- Для генерируемых записей хроники нужны шаблоны с вариантами рода,
  числа и падежа в русском и отдельная английская грамматическая форма.
- Нельзя строить важную подсказку только на русской игре слов без заметки
  локализатору и английского эквивалента смысла.
- Интерфейс в будущем должен выдерживать расширение текста минимум на
  20–30%; шрифт обязан поддерживать латиницу и кириллицу. Конкретный
  визуальный стиль и шрифт пока отложены автором.
- Срок перевода не решён: допустимы RU/EN параллельно или английский
  ближе к завершению Act I. Решение о сроке не должно ломать ключи и
  мастер-имена.

## 8. Что ещё не утверждено

- Самоназвание народа и языка долины.
- Названия домов/хозяйств и родовых линий для социальной модели.
- Финальная проверка благозвучия и нежелательных совпадений.
- Срок RU/EN-релиза и список языков после английского.
- Названия видов, болезней, инструментов и технологий: они должны
  создаваться по этому стандарту, а не заимствоваться из древнерусской
  истории автоматически.
