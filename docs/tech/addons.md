### Зачем каждый

- **Dialogue Manager** — диалоги как текстовые файлы `.dialogue`:
  ветвления, условия, переменные, мутации. Для игры, где лор подаётся через
  персонажей и тексты, экономит недели изобретения велосипеда. Диалоги
  будем класть в `resources/dialogue/`. При включении сам добавит свою
  автозагрузку — это нормально, фиксируем коммит после включения.
- **Phantom Camera** — виртуальные камеры 2D и 3D. Baseline Lock не
  делает его зависимостью: обычная Camera2D со своим сглаживанием и
  зумом проще и предсказуемее для Core. Плагин остаётся выключенным
  кандидатом для особых камерных сцен.
- **Godot State Charts** — кандидат для локальных состояний тела и UI
  в P3. Не использовать как движок мировой/поселенческой симуляции:
  она строится собственными тиками, задачами и данными.

## Как установить/обновить

Скрипты в `tools/` клонируют репозитории плагинов и копируют только папку
аддона в `addons/`:

```bash
# Linux / macOS
./tools/install_addons.sh

# Windows (PowerShell)
./tools/install_addons.ps1
```

Правила обновления:

1. Обновляемся осознанно, по одному плагину, не «заодно всё сразу».
2. После обновления: открыть проект, переимпортировать, прогнать сцены,
   где плагин используется, обновить таблицу выше (версия, commit, дата).
3. Чужие файлы внутри папок плагинов не редактируем — обновления затрут правки.
   Своё поведение строим наследованием/композицией снаружи.
4. Лицензии плагинов лежат внутри их папок и сохраняются в репозитории как есть.
