# scripts/persistence

Статус: **P0-D — мировой документ кампании реализован и прошёл
hardening-gate**. Эта папка отвечает за файловое представление
состояния, а не за саму симуляцию.

## Границы

- `../core/world_state.gd` — доменная правда кампании без Node,
  FileAccess, сети и презентации: campaign ID, Genesis Seed, закреплённые
  пакеты контента, WorldClock, RngStreams, FactLog, allocator runtime
  entity ID и JSON-safe компоненты сущностей.
- `world_state_codec.gd` — конверт мирового сейва v1: формат, версия
  схемы, версия игры, время создания, SHA-256 payload и пошаговая
  миграция legacy `v0 -> v1`. Декодирование сначала строит временный
  `WorldState`; битый payload не заменяет действующую кампанию.
- `save_store.gd` — generic-хранилище JSON-документов по слотам. Оно не
  знает схему мира: записывает временный файл в том же каталоге,
  проверяет байты после записи, ротирует `backup1..N`, перебирает
  кандидатов при загрузке и убирает stale temp-файлы.

Legacy `scripts/autoloads/save_system.gd` остаётся простой заглушкой
меню и **не является сейвом кампании**.

## Текущие ограничения

- Реализована только схема мира. Отдельные схемы персонажа и наследия
  остаются требованием полного P0 и получат собственные codec поверх
  `SaveStore`, когда появятся их доменные модели; их нельзя прятать
  внутрь мирового payload.
- Свежая кампания через `WorldState.setup_campaign` обязана передать
  хотя бы один package pin. Восстановленный legacy payload может иметь
  пустой список pins: `SessionWorldLoader` в P0-E принимает текущий pin
  реестра только для такого мигрированного мира и отклоняет любое
  несовпадение существующих pins.
- Один слот имеет одного писателя. В P0-E `GameSession` разрешает
  сохранение только на хосте и сериализует его внутри сессии;
  межпроцессного lock пока нет. Корень `SaveStore` дополнительно
  отклоняет bare root и `..`, потому что удаление слота рекурсивно.
- Защита рассчитана прежде всего на падение процесса и битую текущую
  копию. `SaveStore` не обещает отдельную гарантию при потере питания:
  Godot `FileAccess.flush()` не равен полному fsync каталога.
- Codec сохраняет pins пакетов (`package_id`, `version`, `manifest_hash`),
  а сверку совместимости с загруженным `DefinitionRegistry` выполняет
  `SessionWorldLoader` при старте и сохранении сессии.
- Fixture `tests/fixtures/saves/world_v0_legacy.json` фиксирует
  минимальный до-P0-D формат только для миграции; это не публичный
  формат модов.

Контракты проверяет `tests/unit/persistence_test.tscn`: round-trip,
checksum tamper, будущая схема, миграция, ротация, fallback на backup,
missing-current crash-окно, stale temp и отсутствующий слот. Сцена
подключена к `tools/check_project.sh` и CI на Godot 4.7.2.
