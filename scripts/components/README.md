# Компоненты

Переиспользуемые кусочки поведения, которые вешаются дочерними нодами
на персонажей/объекты: здоровье, взаимодействие, хитбоксы, инвентарь...

Правило появления: компонент рождается, когда одно и то же поведение
понадобилось **второй раз**. До этого — просто код в своей сцене:
преждевременные абстракции вреднее небольшого дублирования.
