# scripts/core

Чистая логика и данные без привязки к сценам: базовые классы ресурсов,
утилиты, формулы баланса. Если код можно протестировать без запуска сцены —
ему, скорее всего, место здесь (а тестам на него — в `tests/`).

Эта папка не равна всему предметному **Core** игры из дизайн-документов.
Будущая симуляция мира, сеть, генерация и сохранения получат собственные
доменные границы после прототипа; не складываем сюда «весь движок игры»
только из-за названия папки.
