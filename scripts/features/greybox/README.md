# scripts/features/greybox

Статус: **P0-E — авторитетный доменный словарь первого greybox-среза
реализован и прошёл hardening-gate**. Визуальная сцена, камера и debug
overlay появятся в P0-F.

## Состав

- `greybox_world.gd` — минимальный контракт сущностей P0:
  тело участника `core:actor/greybox_body` (`body`, `position`,
  `inventory`) и один изменяемый ящик припасов
  `core:object/greybox_supply_crate` (`position`, `container`,
  `interactable`). Проверяет определения против `DefinitionRegistry`,
  валидирует уже сохранённые тела/объект при загрузке и выдаёт свободные
  стартовые клетки.
- `greybox_intents.gd` — применение двух первых авторитетных намерений:
  `move_body` (шаг на одну свободную клетку в пределах поля и только
  своим телом) и `interact_object` (`take_one` из соседнего ящика в
  инвентарь тела). Каждое успешное действие пишет факт на текущей минуте
  `WorldClock`; при ошибке записи факта изменение компонентов
  откатывается.

Этот модуль не является финальной моделью персонажа, инвентаря или боя.
Его задача в P0 — доказать единый путь
`DefinitionRegistry -> WorldState -> GameSession -> ENet -> SaveStore`
до появления презентации P0-F и доменных срезов P1–P3.
