# Плагины (addons)

Baseline Lock раунда 12: сторонние плагины лежат в репозитории, но **выключены** и не являются зависимостью Core
(`Project -> Project Settings -> Plugins`). Включаем по одному, когда
доходим до соответствующей фичи, — так проект всегда открывается чисто,
а мы точно знаем, какой плагин за что отвечает.

Подробности, версии и обновление: [`docs/tech/addons.md`](../docs/tech/addons.md).

| Плагин | Зачем | Когда включать |
|---|---|---|
| `dialogue_manager` | Диалоги и нарратив: ветвящиеся реплики, условия, переменные — кандидатный инструмент подачи лора, а не выбранная архитектура системного знания NPC | Когда начнём писать первые диалоги/NPC и проверим совместимость с моделью знаний/слухов |
| `phantom_camera` | Камеры 2D/3D: следование, зоны, плавные переходы | Только если собственная Camera2D не закроет конкретную сцену; Baseline Core его не требует |
| `godot_state_charts` | Конечные автоматы для локальных состояний тела/UI | Кандидат на P3; мировая и поселенческая симуляция строится собственными данными/тиками |

Не редактировать код внутри папок плагинов руками: при обновлении правки
потеряются. Обновление — скриптом `tools/install_addons.sh` (или `.ps1`).
