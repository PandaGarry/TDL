# Плагины (addons)

Сторонние плагины лежат в репозитории готовыми, но **выключены**
(`Project -> Project Settings -> Plugins`). Включаем по одному, когда
доходим до соответствующей фичи, — так проект всегда открывается чисто,
а мы точно знаем, какой плагин за что отвечает.

Подробности, версии и обновление: [`docs/tech/addons.md`](../docs/tech/addons.md).

| Плагин | Зачем | Когда включать |
|---|---|---|
| `dialogue_manager` | Диалоги и нарратив: ветвящиеся реплики, условия, переменные — главный инструмент для подачи лора | Когда начнём писать первые диалоги/NPC |
| `phantom_camera` | Камеры 2D/3D: следование, зоны, плавные переходы, кинематографичные пролёты | Когда появится первый игровой уровень |
| `godot_state_charts` | Конечные автоматы для персонажей, врагов, квестов и UI без спагетти из `match` | Когда появится первый персонаж со состояниями |

Не редактировать код внутри папок плагинов руками: при обновлении правки
потеряются. Обновление — скриптом `tools/install_addons.sh` (или `.ps1`).
