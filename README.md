# TDL

Рабочий репозиторий игры на Godot.

## Документы

- [10 концептов игры](docs/10-concepts.md) — открытый мир, строительство, фарм, крафт, мультяшная рисовка и сильный сюжет.
- [Saltvigil · Лор-библия v0.1](docs/lore/saltvigil-lore-bible-v0.1.md) — выбранный мир, крючок «память как топливо», фракции, персонажи, сюжет, DLC-архитектура и Steam-модель.

## Текущее решение

**Saltvigil** — colony sim с открытым миром, плавучим городом-культом, фермой, крафтом и сюжетом. Лор зафиксирован как рабочая гипотеза и ждёт подтверждения перед производством.
