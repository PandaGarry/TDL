# Saltvigil · «Соляная вахта»

Солнце мертво. Его тело стало миром, его сердце — твоим фонарём, а память твоих последователей — топливом. Веди плавучий культ по костям мёртвого бога и реши, что ты готов сжечь, чтобы дожить до утра.

**Жанр:** colony sim + открытый мир + строительство + фарм + крафт + сюжет.
**Движок:** Godot 4.7 (проверено на 4.7.2).
**Статус:** M1 preview v0.2.0. Три ночи, догматы, события, сохранение, тесты.

## Быстрый старт

1. Установить [Godot 4.7+](https://godotengine.org/download) (стандартная сборка).
2. Открыть папку проекта с `project.godot`.
3. Нажать **F5**.

```bash
# headless-тесты
godot --headless --path . res://tests/test_runner.tscn

# линтер
pip install "gdtoolkit==4.*"
gdlint src tests
```

## Что уже есть

- три ночи по шесть вахт, спад света 7/8/9;
- свет, вера, тепло, еда, дерево, воск, соль, пепел;
- три последователя и девять воспоминаний;
- сжечь / сохранить / прочесть память;
- **догматы**: после первой и второй ночи Уэйк принимает закон — навсегда;
- **события ночи**: «Пустая кухня», «Ребёнок у борта», «Соль на губах», «Песня из тумана» — три варианта, флаги решений;
- **свечной дом**: пепел сожжённых памятей становится воском;
- пять зданий и восемь слотов на палубе;
- Журнал Хранителя и чудеса ценой страниц;
- Полы, уход последователей, поражение и финал демо;
- сохранение и продолжение с рассвета (атомарная запись + резервная копия);
- меню, HUD, карточки памяти, стройка, журнал;
- headless-тесты и CI.

Чего пока нет: арт и звук (всё рисуется кодом), крафт, экспедиции и открытый мир —
они в M2–M3 по [плану](docs/production-plan.md). M1 preview проверяет крючок
и экономику: хватает ли одной ночи, чтобы игрок захотел вторую.

## Управление

| Действие | Как |
|---|---|
| Память последователя | клик по токену на палубе или по имени слева |
| Сжечь / сохранить / прочесть | кнопки в карточке памяти |
| Покормить Уголёк | кнопка внизу — **одно подношение за вахту** |
| Принять закон | выбор на экране рассвета |
| Ответить на событие | модальное окно ночи, выбор необратим |
| Чудо | кнопка внизу или в Журнале |
| Строить | «Строить» → здание → свободный слот |
| Отмена стройки | ПКМ или Esc |
| Пауза / закрыть окно | Esc |
| Сохранить | кнопка «Сохранить», автосейв на рассвете |

## Принципы

- данные отдельно от кода;
- состояние отдельно от UI;
- один источник правил (`data/config.json`);
- премиум-игра без микротранзакций и FOMO;
- сначала проверяем крючок, потом рисуем арт.
